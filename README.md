# Luz do Sanātana Dharma

Portal devocional hinduísta em língua portuguesa, inspirado nos Vedas, nas Upaniṣads, no Bhagavad Gītā, no Mahābhārata, no Rāmāyaṇa e nas diferentes tradições do Sanātana Dharma.

## Site oficial

**https://sanatanadharma.com.br**

## Propósito

Oferecer estudo, contemplação e práticas para a vida cotidiana, preservando a diversidade das escolas e linhagens hindus. O conteúdo distingue textos tradicionais, sínteses explicativas e reflexões devocionais.

## Estrutura atual

- Devocional diário rotativo
- Página introdutória do Mahābhārata
- Mapa dos 18 parvas do Mahābhārata
- Apresentação dos personagens centrais do épico
- Trilha dos 18 capítulos do Bhagavad Gītā
- Página navegável para cada capítulo do Gītā
- Contexto, temas, síntese de verso, reflexão, prática e perguntas
- Biblioteca de escrituras e tradições
- Conceitos fundamentais: dharma, karma, mokṣa, Ātman, Brahman e puruṣārtha
- Tema claro e escuro
- Pesquisa e navegação responsiva
- PWA com suporte offline
- Sitemap, robots.txt e metadados básicos de SEO

## Publicação pelo GitHub Pages

O site está localizado na pasta `docs/` e publicado pelo GitHub Pages a partir da branch `main`.

Configuração:

- **Branch:** `main`
- **Pasta:** `/docs`
- **Domínio personalizado:** `sanatanadharma.com.br`
- **Arquivo de domínio:** `docs/CNAME`
- **HTTPS:** deve permanecer ativado em **Settings → Pages → Enforce HTTPS** assim que o certificado estiver disponível.

## DNS

O domínio é administrado pelo Registro.br. Os registros A do domínio raiz e o CNAME de `www` devem apontar para a configuração indicada pelo GitHub Pages.

O arquivo `docs/CNAME` deve conter somente:

`sanatanadharma.com.br`

## Princípios editoriais

- Não reduzir o Hinduísmo a uma única escola.
- Contextualizar o Bhagavad Gītā dentro do Mahābhārata.
- Diferenciar tradução, paráfrase, comentário e reflexão.
- Indicar fontes e tradições interpretativas sempre que possível.
- Evitar sincretismos não declarados.
- Identificar claramente as sínteses de versos, sem apresentá-las como traduções literais.
